Anthropic

Entry tier

  • AI Fluency: Framework and foundations (Anthropic). Course on working with AI using the 4D framework: Delegation, Description, Discernment, Diligence. Entry
  • Claude 101 (Anthropic). Thirteen-lesson course on using Claude for everyday work, from prompting to projects and skills. Entry
  • What are Projects? (Anthropic). Help article on Claude Projects: workspaces with their own chats, knowledge and instructions. Entry
  • Prompt engineering overview (Anthropic). Claude Platform docs overview of prompt engineering techniques for better Claude outputs. Entry
  • Prompt engineering interactive tutorial (Anthropic). GitHub repository for Anthropic's interactive prompt engineering tutorial. Entry

Mid tier

  • Claude Code quickstart (Anthropic). Step-by-step docs for installing Claude Code and running it on a first project. Mid
  • Claude Code overview (Anthropic). Claude Code docs overview of what the tool does and where it runs. Mid
  • Claude Code 101 (Anthropic). Twelve-lesson course on using Claude Code on your own codebase. Mid
  • Common workflows (Anthropic). Docs covering common Claude Code workflows for everyday coding tasks. Mid
  • How Claude remembers your project (CLAUDE.md and memory) (Anthropic). Docs on CLAUDE.md files and memory that carry project instructions across sessions. Mid
  • Best practices for Claude Code (Anthropic). Docs with tips for getting better results from Claude Code. Mid
  • Settings files and precedence (Anthropic). Docs on Claude Code settings files, their precedence and configuration scopes. Mid
  • Extend Claude with skills (Anthropic). Docs on creating and using Claude Code skills to extend what Claude can do. Mid
  • Skills repository on GitHub (Anthropic). GitHub repository of Anthropic's public example skills for Claude. Mid
  • Claude Code in action (Anthropic). Nine-lesson course on running long Claude Code sessions: steering, configuring, automating and verifying. Mid

Advanced tier

  • Create custom subagents (Anthropic). Docs on creating custom Claude Code subagents with their own prompts, tools and context. Advanced
  • Introduction to subagents (Anthropic). Four-lesson course on delegating tasks to Claude Code subagents with their own context windows. Advanced
  • Hooks reference (Anthropic). Reference for Claude Code hooks: events, configuration and how they run. Advanced
  • Connect Claude Code to tools via MCP (Anthropic). Docs on connecting Claude Code to external tools and data through MCP servers. Advanced
  • What is the Model Context Protocol (MCP)? (Anthropic). MCP introduction explaining what the protocol is and what it connects. Advanced
  • Introduction to Model Context Protocol (Anthropic). Course on building MCP servers and clients with the Python SDK: tools, resources and prompts. Advanced
  • Model Context Protocol: Advanced topics (Anthropic). Course on MCP sampling, notifications and roots, with interactive walkthroughs. Advanced
  • Extend Claude with skills (Anthropic). Docs on creating and using Claude Code skills to extend what Claude can do. Advanced
  • Skills repository on GitHub (Anthropic). GitHub repository of Anthropic's public example skills for Claude. Advanced
  • Claude Cookbooks on GitHub (Anthropic). GitHub repository of notebooks and recipes showing effective ways to use Claude. Advanced
  • Best practices for Claude Code (Anthropic). Docs with tips for getting better results from Claude Code. Advanced
