Mid: give it a folder

This tier is for Claude Code, which works on a folder of your files. You will learn to set up a project, give written instructions, and keep the work safe and checkable.

Before you start

  • You need a Claude license that includes Claude Code. The Standard license does. See licenses.
  • School-managed laptops often block installs. A JHU install path is Coming soon. Ask your local IT.
  • Try the Entry tier first if chat is new to you.

Steps

  1. Install Claude Code and open the terminal. Claude Code runs in a terminal window, so this is where you work.
    • Claude Code quickstart (Anthropic). Step-by-step docs for installing Claude Code and running it on a first project.
    • Claude Code overview (Anthropic). Claude Code docs overview of what the tool does and where it runs.
    • Claude Code 101 (Anthropic). Twelve-lesson course on using Claude Code on your own codebase.
  2. Set up a project folder. A folder per project keeps the agent focused on the right files.
    • Common workflows (Anthropic). Docs covering common Claude Code workflows for everyday coding tasks.
  3. Write instructions in a CLAUDE.md file. A CLAUDE.md file is a note the agent reads at the start of every session. A JHU template is Coming soon, planned for February 15.
    • How Claude remembers your project (CLAUDE.md and memory) (Anthropic). Docs on CLAUDE.md files and memory that carry project instructions across sessions.
  4. Plan before acting. Plan mode lets you read and correct the agent's plan before it changes anything.
    • Best practices for Claude Code (Anthropic). Docs with tips for getting better results from Claude Code.
  5. Set permissions and keep sensitive files out. You decide what the agent may read, write and run. Follow the data rules.
    • Settings files and precedence (Anthropic). Docs on Claude Code settings files, their precedence and configuration scopes.
  6. Use version control as an undo button. Git saves snapshots of your folder, so you can always go back. The common workflows page shows how Claude Code uses it.
  7. Use shared skills. A skill is a saved set of instructions the agent loads when needed.
    • Extend Claude with skills (Anthropic). Docs on creating and using Claude Code skills to extend what Claude can do.
    • Skills repository on GitHub (Anthropic). GitHub repository of Anthropic's public example skills for Claude.
  8. Have the agent check its own work. Ask for tests, checks or a second look, then review the result yourself.
    • Claude Code in action (Anthropic). Nine-lesson course on running long Claude Code sessions: steering, configuring, automating and verifying.

An alternative tool

  • OpenAI Codex on GitHub (OpenAI). A coding agent from OpenAI that runs in the terminal, if you prefer it.
