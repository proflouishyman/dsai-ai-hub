Entry: use AI well in chat

This tier is for using AI in a chat window. You will learn to ask clear questions, use your own sources, and check what comes back.

Before you start

  • You need a browser and your JHU sign-in.
  • Read the data rules first.
  • Reading and watching need no license. Small groups do.

Steps

  1. Learn how AI chat tools work and where they fail. Knowing the limits helps you judge what they tell you.
    • AI Fluency: Framework and foundations (Anthropic). Course on working with AI using the 4D framework: Delegation, Description, Discernment, Diligence.
    • Claude 101 (Anthropic). Thirteen-lesson course on using Claude for everyday work, from prompting to projects and skills.
  2. Know JHU's approved tools and what data may go in. Claude and HopGPT are approved. Some data must never go in.
    • Read the data rules and the licenses and access page.
    • Claude Licenses for JHU (JHU). JHU IT page on Claude licenses for faculty, staff and students.
  3. Prompt with your own sources. Load your own papers or notes into a Claude Project so answers rest on material you trust.
    • What are Projects? (Anthropic). Help article on Claude Projects: workspaces with their own chats, knowledge and instructions.
    • Prompt engineering overview (Anthropic). Claude Platform docs overview of prompt engineering techniques for better Claude outputs.
    • Prompt engineering best practices for ChatGPT (OpenAI). Help article with tips on crafting effective prompts to get better results from ChatGPT.
  4. Ask for code instead of answers. Code can be rerun and checked. For example, ask Claude for Python that tallies a spreadsheet, then run it yourself.
  5. Check the output and the citations. AI can state false things with confidence, including invented references.
    • AI Foundations for Academic Work guide (JHU). Library guide on what AI is, how it works and how to evaluate its outputs.
  6. Know when not to use AI. Some tasks, and some data, call for leaving it out.
    • Guidelines for Responsible Use of AI (JHU). JHU IT guidelines for responsible use of AI across Johns Hopkins University and Medicine.
  7. Practice and look at other tools. A few exercises and a second tool show you what is general and what is specific.
    • Prompt engineering interactive tutorial (Anthropic). GitHub repository for Anthropic's interactive prompt engineering tutorial.
    • OpenAI Academy home (OpenAI). OpenAI Academy home with courses, events, communities and stories on AI skills.
    • OpenAI Academy: Education collection (OpenAI). OpenAI Academy collection of education resources, tagged ChatGPT, Education and Educators.
