Advanced: build systems others can run

This tier is for building agent systems that your lab or department can rely on. You will learn to split work among agents, connect tools, and verify results at scale.

Before you start

  • We suggest finishing the Mid tier first.
  • You need a Claude license that includes Claude Code. See licenses.
  • Advanced runs as colloquia from March 1. Advanced small groups start in fall 2027.

Steps

  1. Use subagents and choose models by cost. Subagents are helper agents with their own working space. Smaller models cost less and suit simple jobs.
    • Create custom subagents (Anthropic). Docs on creating custom Claude Code subagents with their own prompts, tools and context.
    • Introduction to subagents (Anthropic). Four-lesson course on delegating tasks to Claude Code subagents with their own context windows.
  2. Add hooks and automatic checks. A hook runs your own command at set moments, such as after every edit.
    • Hooks reference (Anthropic). Reference for Claude Code hooks: events, configuration and how they run.
  3. Connect other systems with MCP. The Model Context Protocol (MCP) lets agents reach tools and data. IT@JH handles requests for a JHU connector.
    • Connect Claude Code to tools via MCP (Anthropic). Docs on connecting Claude Code to external tools and data through MCP servers.
    • What is the Model Context Protocol (MCP)? (Anthropic). MCP introduction explaining what the protocol is and what it connects.
    • Introduction to Model Context Protocol (Anthropic). Course on building MCP servers and clients with the Python SDK: tools, resources and prompts.
  4. Go deeper on MCP. Advanced topics cover how servers and clients talk to each other.
    • Model Context Protocol: Advanced topics (Anthropic). Course on MCP sampling, notifications and roots, with interactive walkthroughs.
  5. Write and share skills. A shared skill lets a whole lab work the same way. Anthropic's public examples are a good start.
    • Extend Claude with skills (Anthropic). Docs on creating and using Claude Code skills to extend what Claude can do.
    • Skills repository on GitHub (Anthropic). GitHub repository of Anthropic's public example skills for Claude.
  6. Use APIs and high-performance computing. Scripts can call models directly and run at scale on JHU's research clusters.
    • HopGPT API access (JHU). HopGPT support page on API access to JHU's language models.
    • ARCH Clusters Guide (JHU). Documentation for JHU's ARCH research computing clusters.
    • Claude Cookbooks on GitHub (Anthropic). GitHub repository of notebooks and recipes showing effective ways to use Claude.
  7. Compare with the OpenAI cookbook. Seeing a second maker's recipes shows which ideas carry across tools.
    • OpenAI Cookbook (OpenAI). Searchable collection of OpenAI cookbook examples and guides for building with the API.
  8. Verify at scale. Keep provenance (where each value came from), add review passes, and write down data contracts (the shape of each input and output).
    • Best practices for Claude Code (Anthropic). Docs with tips for getting better results from Claude Code.
